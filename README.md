# VibeMap

Живая минималистичная карта атмосферы города: метки живут от 1 до 6 часов и показывают реальную обстановку прямо сейчас.

## Возможности
- Тёмная интерактивная карта на Leaflet + CartoDB Dark Matter.
- Эфемерные метки с фото, тегами, временем жизни (1–6 ч) и подтверждением «Актуально (+30м)».
- Реалтайм-синхронизация через WebSocket: новые метки, реакции и комментарии прилетают мгновенно.

## Локальный запуск
```bash
npm install
npm start
```
По умолчанию порт `3002` (`http://localhost:3002`).
